# Figures

`wsm_method_overview.svg` is an authored vector SVG: its typography, boxes, arrows, and labels are native SVG elements, with no raster embedding. It uses a restrained black/gray palette for manuscript use. `wsm_method_overview.pdf` is its local headless-Chrome PDF export for direct `pdflatex` inclusion; both are vector files.

The figure depicts only the primary shared-fusion candidate's supported training path: online audio/video inputs, availability-aware shared fusion, masked observed supervision, and accepted reliability-weighted direct pseudo-supervision. Full R4 and temporal audio are labelled as frozen reference and baseline rather than shown as a new combined method.
